# 博弈论（一）—— Nim 游戏与必胜必败态

## 1. 引入：什么是算法竞赛中的博弈？

> 两个人玩一个游戏，双方都绝顶聪明（总是选最优策略）。给你游戏的初始状态，问先手能不能赢。怎么判断？

这就是 ICPC 博弈论的核心问题。

**公平组合游戏（ICG）必须满足四个条件：**

1. 两个玩家轮流行动
2. 完全信息（双方都知道全部游戏状态，没有"手牌"）
3. 有限步终止（不会无限循环）
4. 不能行动者输

> 围棋、五子棋不是 ICG（有先手优势、可能平局）。Nim 游戏、取石子是 ICG。

---

## 2. 必胜态与必败态：博弈论的基石

### 比喻：站在终点往前看

想象一个迷宫，终点是"没有合法操作的人输"。

- **P-position（必败态）**：你站在这个位置，不管选哪条路，对手都能让你输
- **N-position（必胜态）**：你站在这个位置，至少有一招能让对手进入必败态

### 三条铁律

> 1. **终态是 P 态**（无法行动 → 输）
> 2. **能走到 P 态的，就是 N 态**
> 3. **所有路都走到 N 态的，才是 P 态**

### 用 DP 理解（小范围通用法）

```cpp
// 问题：n 个石子，每次可取 1/2/3 个，取完者胜。先手能赢吗？
vector<bool> dp(n + 1, false);   // dp[i] = 先手面对 i 个石子能否必胜
for (int i = 1; i <= n; i++) {
    for (int take : {1, 2, 3}) {  // 枚举所有合法操作
        if (i >= take && !dp[i - take]) {
            dp[i] = true;  // 能让对手进入必败态 → 自己必胜
            break;
        }
    }
}
// dp[n] 就是答案
```

**复杂度**：O(n × 操作数)。n ≤ 10^5 可行，n ≤ 10^9 不能用 DP——需要找数学规律。

## 3. 巴什博弈：博弈入门的第一个公式

### 问题

> 一堆 n 个石子，每次取 [1, m] 个。取走最后一个的赢。问先手必胜还是必败？

### 提示

> 从 n=0 开始倒推！n=0 是必败（终态）。n=1,2,...,m 都可以一步取完 → 必胜。n=m+1 时，无论取几个，都留给对手 [1,m] 的范围 → 必败。

**规律**：当且仅当 **n % (m+1) == 0** 时必败。

```cpp
bool bash(int n, int m) { return n % (m + 1) != 0; }
```

**直觉**：你总能"补齐"到 m+1 的倍数——对手取 x，你就取 (m+1-x)。但如果开局就是 m+1 的倍数，对手也能这样对付你。

### 变体：取最后一个的输

> 规则反转——取完者输。等价于 (n-1) 个石子的标准巴什博弈。

**经典题**：HDU 1846 Brave Game

## 4. Nim 游戏 —— 博弈论的王者

### 问题

> n 堆石子，第 i 堆有 aᵢ 个。每次从 **某一堆** 中取走 **任意正数** 个。取走最后一个的赢。问先手必胜？

### 提示

> DP 做不了——状态空间是各堆数量的乘积，n=3 堆每堆 100 个就爆了。
>
> 这个问题的答案极其简洁——**把所有堆的个数异或起来**：
>
> X = a₁ ⊕ a₂ ⊕ ... ⊕ aₙ
>
> - X = 0 → **必败**
> - X ≠ 0 → **必胜**
>
> 这就是 **Bouton 定理（1901）**，博弈论最伟大的发现之一。

### 证明（分两步，每步 5 分钟讲清楚）

**第一步：X = 0 的任意后继 X' ≠ 0**

假设从第 k 堆取 x 个（0 < x ≤ aₖ），新堆 = aₖ - x ≠ aₖ。
X' = X ⊕ aₖ ⊕ (aₖ - x) = 0 ⊕ aₖ ⊕ (aₖ - x)。

因为 aₖ ≠ aₖ - x，所以 aₖ ⊕ (aₖ - x) ≠ 0，故 X' ≠ 0。✓

**第二步：X ≠ 0 时存在一种取法使 X' = 0**

设 X 的二进制最高位为第 d 位（X ≠ 0，所以 d 存在）。至少有一堆 aₖ 的第 d 位也是 1（否则 X 的第 d 位不会是 1）。

目标：取 x = aₖ - (aₖ ⊕ X) 个。可以证明 aₖ ⊕ X < aₖ（因为最高位 d 被消掉了），所以 x > 0，合法。

X' = X ⊕ aₖ ⊕ (aₖ ⊕ X) = 0。✓

> **给听众的直觉**：异或和是游戏的"平衡器"。X=0 是完美平衡——无论对手怎么打破它，你都能恢复平衡。这就是你把对手一步一步逼到失败的方式。

### 模板

```cpp
#include <iostream>
using namespace std;

int main() {
    int m; cin >> m;
    int res = 0;
    for (int i = 0; i < m; i++) {
        int x; cin >> x;
        res ^= x;
    }
    if (res) cout << "Yes" << endl;
    else cout << "No" << endl;
    return 0;
}
```

**复杂度**：O(n) 时间，O(1) 空间。n 可以高达 10^6。

## 5. 反 Nim（Misère Nim）—— 规则反转

### 问题

> 和标准 Nim 唯一的区别：**取走最后一个的输**。

### 提示

> 不是简单把标准 Nim 的结果取反！关键在于"全 1 的堆"是一个特殊情况。
>
> - **全是 1 的堆**：看堆数的奇偶——**偶数必胜，奇数必败**（因为双方都会被逼着取完整的堆，最后取的输）
> - **存在 >1 的堆**：和标准 Nim 完全一样！X ≠ 0 必胜
>
> 为什么有 >1 的堆就回退到标准 Nim？因为你可以控制"谁拿最后一个"——有 >1 的堆就有操作空间。

```cpp
bool anti_nim(vector<int>& a) {
    int x = 0, cnt = 0;
    for (int v : a) {
        x ^= v;
        if (v > 1) cnt++;
    }
    if (cnt == 0) return a.size() % 2 == 0;  // 全1：偶数必胜
    return x != 0;  // 有大于1的堆：同标准Nim
}
```

**经典题**：HDU-1907 John

## 6. 例题精讲

### 例题 1：洛谷 P2197 【模板】Nim 游戏 ⭐

**题意**：标准 Nim。多组数据，每组给 n 堆石子，判断先手胜负。

**思路**：Bouton 定理直接套。X ≠ 0 → "Yes"。

> 这道题唯一的意义是让你亲手验证 Nim 和的神奇——几个数异或一下，就能判断胜负。

### 例题 2：CF 1382B Sequential Nim ⭐⭐

**题意**：n 堆石子排成一排，必须从最左边的非空堆取。取最后一个的赢。

**提示**：

> 从左往右扫描。第一堆如果只有 1 个 → 被迫取完，控制权交给对手。第一堆如果 >1 → 你可以选择取完（把控制权交出去）或留 1 个（保持控制权）。所以**第一个 >1 的堆的位置决定了胜负**！

```cpp
bool sequential_nim(vector<int>& a) {
    int first_big = -1;
    for (int i = 0; i < a.size(); i++)
        if (a[i] > 1) { first_big = i; break; }
    if (first_big == -1) return a.size() % 2 == 1;  // 全是1
    return first_big % 2 == 0;  // 先手先到达>1的堆
}
```

**一句话总结**：「谁先摸到 >1 的堆，谁就有控制权」。

## 8. 常见错误

| 错误 | 正确 |
|------|------|
| `a^b^c` 写成 `a&b&c` | 异或是 `^`，不是 `&` |
| 反 Nim 直接取反 | 全1特判 + 标准Nim |
| 用 DP 硬算 n=10^9 的博弈 | 找数学规律 |
| Nim 的结论用到非 ICG 游戏 | Nim 只对 ICG 有效 |
