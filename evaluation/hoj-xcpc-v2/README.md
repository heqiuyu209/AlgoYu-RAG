# XCPC 新查询检索回归 v2

12 份原创合成讲义、66 个问题（50 个有依据，16 个无依据），calibration / heldout 各 33。50 个有依据问题含两道跨资料比较题，合计 52 组证据。新增主题与旧 v1 资料分离；由编码助手编写明确小节 / 原文证据标注，不宣称真人查询、人工专家复核或标准外部基准。

在实现关键词检索、查看任何新版检索排名前固定数据和哈希。calibration 可用于明确方案，heldout 只用于该次比较；报告首次查看后不得把它继续称为未见样本，不得删改失败题或证据来提高数字。原 v1 继续作为已有行为回归，不替代这批新增查询。

覆盖公式、英文标识符、中文转述、近似但未覆盖的知识、现实世界信息缺失、精确授权范围及空范围。按正确文档 / 小节 / 全部证据字符串衡量命中，候选不等于可回答。没有聊天模型或外网文档抓取。

评测仍使用 scripts/evaluate_hoj_retrieval.py，需显式传 --dataset 本目录；真实本地 BGE-M3 + 独立临时 Qdrant / SQLite，禁止连接现有 HOJ 数据或服务索引。freeze.json 记录本次固定材料，当前结果与整体进度在 HOJ TODO 维护。
