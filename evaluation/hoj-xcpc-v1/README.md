# XCPC 知识库检索评测集 v1

本目录讲义和问题均为项目内原创验收资料，不是竞赛真题或权威教材。只用于可重复的检索评测，不自动进入 HOJ 正式知识库，也不代表生产资料的质量。

12 份中文算法讲义包含中英文术语、公式、代码、边界与相近知识点。78 个问题中 54 个有依据（共 56 组证据），24 个无依据；包含 4 个英文有依据提问及 2 个多证据比较题。问题的 `relevant` 指定文档、实际小节和需要同时出现的证据字符串，不能只按文档题名计为命中。无答案问题区分资料未覆盖和授权范围不包含；`reason` 解释人工标注依据。calibration / heldout 在首次测量前固定；不根据检索结果改标签、挪动问题或删除失败项。后续调整讲义 / 标签需新版本并保留原报告。

指标包括 evidence recall@1/3/5、所有证据均覆盖的 success@3、首个相关证据 MRR@5、引用完整性，以及无答案问题仍有候选的比例和分数分布。Recall 的分母是人工标注证据组数，不能用“有返回值”替代命中。无答案样例中的相近候选不是答案，也不能据其相似度宣称可信。

评测脚本使用同一个 KnowledgeIndex / 切片器、真实本地 BGE-M3 与独立临时磁盘 Qdrant，完成后关闭和清理，不读取原型 `.env`、现有索引、HOJ 数据库或任何用户 Key；不会调用聊天模型。报告保留每题的实际排名 / 分数 / 命中与错误，质量门槛不通过时仍写出报告并以非零状态退出。纯指标单元测试使用人工结果，与实际语义评测分别记录。

```powershell
python scripts/evaluate_hoj_retrieval.py --model 'D:\完整本地BGE-M3目录' --output 'D:\临时证据目录\retrieval.json'
```

默认只要求有答案问题的 recall@3 >= 0.90，不能据此宣布拒答或生成质量通过。脚本另外仅用 calibration 计算满足召回保留 >= 0.90 / 无答案放行 <= 0.05 的候选分数阈值，再独立报告 heldout 结果；不存在可用阈值时明确记录，不把阈值强加给线上服务。小样本上的通过也不是统计保证。后续真实模型的逐结论支持、无依据拒答和诱导指令仍需单独评测。

2026-10-19 已完成原投影与带标题 / 章节上下文投影的同集回归，见 [实际报告](../../docs/hoj-evaluation.md)。原 heldout 结果已被观察并用于定位问题，因此修正后的同组结果是诊断后的回归，不能称为未见样本验证；分数阈值仍仅使用 calibration，未用 heldout 调参。题集及标签未变。
