# 背包动态规划

## 0/1 背包

每件物品最多取一次。dp[j] 表示容量不超过 j 时的最大价值，转移 dp[j]=max(dp[j],dp[j-w]+v)。一维压缩时容量 j 必须从大到小遍历，保证读取上一件物品处理后的状态，防止同一物品在一轮里被重复使用。时间 O(nW)，空间 O(W)。

## 完全背包

每种物品可以取无限次。相同转移式的一维实现让容量从小到大遍历，允许本轮刚更新的状态继续使用当前物品。物品重量应为正；零重量且正价值、数量无限会使最优值无界。

## 恰好装满

若要求恰好装满容量 W，初始 dp[0]=0，其余设为负无穷；不能将所有 dp 初始化为 0 后把不可达容量当成可行方案。转移前跳过不可达状态，避免哨兵加法溢出。
