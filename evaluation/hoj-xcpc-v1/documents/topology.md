# 有向无环图与拓扑排序

## Kahn 入度法

统计每点入度，把所有入度为 0 的点放入队列；每次弹出一点并删除它的出边，邻居入度减到 0 时入队。若最终输出点数小于 n，图中存在有向环；输出 n 个点则得到一种拓扑序。复杂度 O(n+m)。

## 依赖与最长路径

课程先修或构建任务依赖可建为有向边。DAG 上按拓扑顺序更新 dp[v]=max(dp[v],dp[u]+w)，每条边处理一次。最长路径的起点与初始不可达值需根据题意设置；有向有环图不能直接套用这个 DAG 递推。

## 序列不唯一

拓扑序可能不唯一。若要字典序最小的拓扑序，将普通队列改为维护当前所有零入度点的小根堆，不是把最后得到的序列直接排序。
