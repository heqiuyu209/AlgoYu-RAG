# 广度优先搜索与网格

## 无权最短路径

BFS 使用先进先出队列，起点距离设为 0。未访问邻居的距离等于当前距离加 1，在入队时标记访问，避免同一位置反复入队。它计算单位边权图的最少步数；一般带权最短路不适用这个简单模板。

## 多源扩散

若要求每个空格到最近一个起点的距离，先将所有起点以距离 0 同时加入队列，再进行一次 BFS。这是多源 BFS，复杂度仍为 O(点数+边数)，不需要对每个起点单独搜索再取最小值。

## 网格边界

四方向邻接时，先检查新坐标在范围内、不是障碍、尚未访问，再入队。需要恢复路径时记录首次到达的前驱。不可达位置保持特殊值，例如 -1，不用 0 混同起点。
