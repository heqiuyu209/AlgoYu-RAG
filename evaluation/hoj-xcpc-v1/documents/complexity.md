# 算法复杂度与整数

## 时间规模估计

两层循环各执行 n 次，总操作规模 O(n²)。当 n=200000 时，n² 为 40000000000，通常不能据小样例运行快就认为可行。哈希表均摊常数、并查集近似常数等说法有适用前提，不能替代最坏情况分析。

## 乘法发生前的类型

C++ 中 int a,b; long long x=a*b; 仍先以 int 做乘法，再转换赋值，可能已溢出。应写 long long x=1LL*a*b;，让乘法发生在更宽类型中。若乘积仍超出 long long，需额外方案，不能认为加了 1LL 就永不溢出。

## 空间复杂度

大小为 n*m 的二维数组空间为 O(nm)，常见 int 元素占 4 字节。递归还需要调用栈；链状图递归 DFS 深度可能达到 n，应考虑迭代写法或运行栈限制。本讲义不估计某台评测机的精确秒数。
