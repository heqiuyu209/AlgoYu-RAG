# 树状数组 Fenwick Tree

## 单点增加与前缀和

下标从 1 开始，lowbit(x)=x&(-x)。单点增加时沿 i+=lowbit(i) 更新；求前缀和时沿 i-=lowbit(i) 累加。两者时间复杂度均为 O(log n)，区间 [l,r] 的和用 query(r)-query(l-1)。更新循环不能从 0 开始，因为 lowbit(0)=0 会导致下标不前进。

## 与静态前缀和的取舍

静态前缀和查询 O(1)，但单点修改会影响后续大量前缀值；树状数组牺牲常数查询时间，换来 O(log n) 的单点修改。普通求和树状数组不能仅把加法换成 min 就直接支持任意区间最小值和任意修改；需要不同结构或额外限制。

## 本讲义范围

这里仅讲单点增加、前缀和及区间和转换。不包含两棵树状数组维护区间加区间和，也不包含逆序对和离散化的推导。
