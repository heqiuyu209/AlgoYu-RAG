# 前缀和与差分

## 静态区间求和

数组下标从 1 开始，定义 S[0]=0，S[i]=S[i-1]+a[i]。闭区间 [l,r] 的元素和为 S[r]-S[l-1]。预处理 O(n)，每次查询 O(1)。这适合原数组不再改变的大量区间求和；有负数也能使用前缀和，不要求数组单调。注意 l=1 时读取的是 S[0]，不能访问负下标。

## 批量区间加

差分数组 D[i]=a[i]-a[i-1]。把闭区间 [l,r] 的每个数增加 x，只需 D[l]+=x，D[r+1]-=x。全部修改完成后做一次前缀累加即可恢复数组。空间须容纳 r+1；普通差分适合批量修改、最后还原，不直接支持每次修改后高效区间求和。

## 数值范围

当 n=200000 且每项可达 1000000000 时，总和可达 200000000000000。C++ 中用 long long 存前缀和与答案；数组单项能放进 int 不代表总和能放进 int。
