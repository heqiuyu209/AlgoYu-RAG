# 并查集 Disjoint Set Union

## 集合代表与合并

find(x) 返回 x 所在集合的代表。判断两点是否连通比较 find(x)==find(y)，不能直接比较 parent[x] 与 parent[y]。合并先找根，再将一个根连到另一个根；相同集合无需重复合并。

## 路径压缩与按大小合并

路径压缩让查找路径上的节点直接指向根；按大小合并把较小集合的根接到较大集合。两者结合时，m 次操作的总复杂度为 O(m α(n))，α 是反阿克曼函数，常用规模下增长极慢。它不是“每次最坏严格 O(1)”的证明。

## 删除操作

普通并查集适合只加边的连通性，不能直接高效删除一条边并拆分集合。离线反向处理或可回滚并查集需另行设计，本讲义没有给出实现。
