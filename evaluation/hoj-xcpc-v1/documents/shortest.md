# 非负权最短路 Dijkstra

## 非负边权前提

Dijkstra 每次确定当前距离最小的未确定点。边权必须非负，权重为 0 可以；存在负权边时，这个贪心确定过程不再保证正确。负环及负权最短路的其他算法不在本讲义范围。

## 堆与过期状态

邻接表配优先队列时，堆中可保留同一点的多个候选。弹出 (d,u) 后若 d!=dist[u]，跳过这个过期状态；成功松弛时再插入新候选。常见稀疏图实现复杂度写作 O((n+m) log n)。别在第一次入堆时就把顶点永久标记为确定。

## 无权图的选择

所有边权相同且视为单位代价时，普通 BFS 按层扩展即可求最少边数，复杂度 O(n+m)。当边权不同，仅按队列层数搜索不能代替加权最短路。
