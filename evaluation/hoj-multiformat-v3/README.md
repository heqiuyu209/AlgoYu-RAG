# 多格式知识库检索评测 v3

8 份原创合成资料（Markdown、TXT、PDF 页码正文、视频字幕各 2 份），44 个问题，calibration / heldout 各 22。36 个有依据问题共 40 组证据，8 个无依据问题含近似知识、资料缺失和授权范围限制。题目和标签由编码助手编写，未经过真人查询采集或专家独立审核；“新题集”仅表示首次测量前没有观察这批检索排名。

documents.json 是资料格式、题名、来源文件和稳定 ID 的清单。PDF 样例是已经提取 / 校订后的规范正文，保留空白第 2 页；视频样例是已校订字幕时间轴，片段跨过 60 秒。它们用于验证检索和引用定位，不是原始 PDF 提取、OCR 或语音识别的质量评测，也不连接用户资料库。

freeze.json 在首次 Embedding 测量前记录全部来源、清单和问题的 SHA-256。不得为了提高结果删题、改标注、替换资料、调整 0.90 门槛；查看首轮结果后，这套材料只能作为已观察的回归集。旧 v1 / v2 的文件保持原样。

复用 scripts/evaluate_hoj_retrieval.py 的生产分块、本地 BGE-M3 与临时 Qdrant / SQLite。文档 / 小节 / 全部标注原文同时匹配才计命中；额外按物理页或时间轴重新核验返回片段，并按格式分别报告证据召回。跨格式问题的排名按完整候选列表计数，不能先筛选格式再计算。来源定位正确不表示生成结论得到资料支持，候选的 cosine 也不是回答置信度。

本轮只评估当前 dense 模式；没有接入新模型或更改线上排序。无依据问题仍可返回候选，单独统计，不把它计成拒答成功。真实本人问答模型、逐结论语义支持和未见真实课堂材料仍待验收，按用户选择不重复索要 Key。
